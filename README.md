# المحاضرة الأولى — Academic AI Light

نسخة Streamlit محسنة للعرض في المدرج:
- واجهة فاتحة ومريحة للعين.
- خط عربي أكبر وواضح.
- فهرس ثابت على يمين الصفحة.
- قراءة متتابعة من أعلى المحاضرة إلى أسفلها.
- جداول تعليمية ملونة ومتناسقة مع الواجهة.
- رسوم AI/ML/DL متحركة خفيفة.
- شبكة عصبية 3D تفاعلية فقط في الموضع الذي يخدم الفكرة التعليمية.

## التشغيل
```bash
pip install -r requirements.txt
streamlit run app.py
```

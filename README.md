# المحاضرة الأولى — تطبيقات التعلم العميق لطلبة إدارة الموارد البشرية

نسخة Streamlit تفاعلية بتصميم عربي RTL، قراءة متتابعة، فهرس جانبي على اليمين، جداول حديثة، مخطط متحرك لتوضيح العلاقة بين AI وML وDL، ورسم ثلاثي الأبعاد مبسط للشبكة العصبية.

## التشغيل محليًا

```bash
pip install -r requirements.txt
streamlit run app.py
```

## الملفات
- `app.py`: التطبيق الرئيسي.
- `requirements.txt`: المكتبات المطلوبة.

## ملاحظات التصميم
- الحركة تستخدم عندما تضيف معنى تعليميًا.
- الرسم 3D مستخدم لتوضيح تتابع الطبقات فقط.
- الجداول والبطاقات موحدة الألوان مع هوية الواجهة.
- اتجاه الكتابة RTL محفوظ في المحتوى والفهرس والجداول.
